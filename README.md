## 🧩 Featured Projects

### 🎓 Attendance Management System with Face Recognition

A **real-time attendance management web app** that uses **face recognition** to mark
student attendance automatically through a webcam — no manual entry, no photos stored,
and duplicate-proof by design.

Built as a **full-stack + computer-vision** project with a **Next.js frontend**, a
**Python FastAPI microservice** for face processing, and a **SQLite database** managed
through Prisma. Face data is stored as a **128-dimensional encoding** (never the image
itself), keeping the system small, fast, and privacy-safe.

#### Key Features

* 🎥 **Real-time face recognition** via webcam — auto-marks attendance on match
* 🔐 **Admin authentication** — cookie-based session, edge middleware–protected routes
* 🌐 **Public attendance page** — no login required for students/operators
* 📊 **Live dashboard** — Total Students · Present Today · Absent Today · Attendance %
* 👥 **Student management** — full CRUD with search, gender, class, and year
* 📚 **Class & year management** — add, rename, delete with duplicate prevention
* 🧠 **Face registration** per student via webcam
* 🚫 **Duplicate attendance prevention** — DB-enforced `UNIQUE(register_number, date)`
* ✅ **Frontend + backend validation** on every field
* 🎨 **Clean, responsive UI** — green brand theme, mobile-friendly, sidebar + topbar
* 🪟 **Cross-platform setup** — includes `setup.bat` / `start.bat` for Windows

**Tech Stack:** Next.js • TypeScript • Tailwind CSS • Prisma • SQLite • Python • FastAPI • OpenCV • dlib • face_recognition

**Repo:** [Attendance-Management-Web-App-with-Face-Recognition](https://github.com/Praveenkanth2805/Attendance-Management-Web-App-with-Face-Recognition)

> This project was a major step in my journey — building **two separate user surfaces**
> (public + admin), integrating a **Python computer-vision microservice** with a
> **Next.js backend**, and handling **end-to-end validation, state management, and
> privacy** correctly.
